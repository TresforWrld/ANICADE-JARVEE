ANICADE VISION: Tactical Screen Suite

Local OCR engines, free visual generators, and zero-setup efficiency.

Welcome to the updated ANICADE VISION dashboard, engineered to operate locally first with optional developer-side API upgrades. It scans images, camera feeds, or desktop screens, then answers with speech, output text, and copy-ready responses.

2

ANICADE VISION Voice Guide

Speak naturally to command Anicade (ensure the microphone Orb is active):

Reading & Analysis

  • "Read screen" - Runs vision/OCR and speaks the detected text.
  • "Explain screen" - Explains what is currently shown.
  • "Scan this document" - Analyzes text from camera capture.

Task Automation

  • "Help me with this school question" - Translates and explains equations/slides.
  • "Suggest a reply" - Scans visible message layout and suggests replies.
  • "Reply to message I am running late" - Drafts a direct copy-ready response.
  • "Generate an ad for [product]" - Generates clean ad material with or without a reference image.
  • "Open WhatsApp" - Attempts device app launch with a web fallback.
  • "Internet scan ANICADE TECH" - Runs live search only when explicitly requested.
  • "Read website https://example.com" - Summarizes a readable website page.

Utility Dictation

  • "Start voice typing" - Enters notepad mode where spoken words are typed directly.
  • "Stop typing" - Returns to general screen reading/chatbot mode.
  • "Clear notebook" - Erases notepad context.

Settings & Scheduling

  • "Change voice to Friday" - Switches to a matching browser voice.
  • "List voices" - Reads available voice names.
  • "Change persona to Mentor" - Switches the assistant personality.
  • "Add schedule project review at 3:30 PM" - Writes the reminder into the schedule panel.
  • "Clear schedules" - Removes every saved reminder.
  • "Open file" - Opens the browser file picker for supported local files.
  • "Open maps" / "Map of Lusaka" - Opens the map surface and docks the Orb.
  • "Particles on" / "Dark mode" - Updates visual settings by voice.

Creative Ad Banner Generation

ANICADE VISION includes a free Image Ad Generator connected to Pollinations.ai. You can create advertising campaigns dynamically.

How to generate ads?

1. Share a document or product page on screen (or upload an image).
2. Click the "Image Ad Generator" tool, or speak: "generate ad for [product/theme]".
3. ANICADE VISION can use a shared reference image or proceed from your product/theme description alone.
4. Click "Save Ad Banner" to download the image file to your device.

Immersive Standalone PWA setup

Launch ANICADE VISION directly from your desktop or phone homescreen. Use Chrome or Edge for microphone, camera, screen share, local folders, voice recognition, and install prompts.

Desktop PCs

  • Tap the animated "Install App" button next to status in top header.
  • Confirm the browser installation prompt.
  • Launches full-screen with no browser address bars for clean HUD aesthetic.

Mobile Devices

  • Tap Install App at the top bar.
  • On iOS, tap Safari's Share icon and select Add to Home Screen.
  • This loads service workers in the background, permitting offline usage.

Local Setup

  • Copy config.example.js to config.js.
  • Keep config.js private; do not upload real API keys to public GitHub Pages.
  • Run start-anicade.bat or npm.cmd start, then open http://127.0.0.1:8000.

Reminders

  • Allow notifications when your browser asks.
  • Keep the app open for local reminder alerts.
  • Use commands like "remind me to check email tomorrow at 9 AM".
